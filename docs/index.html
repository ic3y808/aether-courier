⚡ IMAP IDLE push 🤖 Agentic Copilot 📬 iCloud · Gmail · Outlook · Proton 💾 Offline‑capable cache

Not a chatbot bolted on the side

The Copilot is an agent that takes real actions across your mailboxes — and it runs on a local LLM via Ollama or LM Studio.

🔒

Local‑first AI

The Copilot talks to Ollama / LM Studio on your machine by default. Point it at any OpenAI‑compatible endpoint if you prefer.

🤖

It does your chores

Summarise unread & flag important, sort inboxes into folders, report spam across a whole sender, empty trash/spam, unsubscribe, phishing checks, draft replies, calendar events, read PDF/image attachments.

⚡

Real push, never polling

New mail arrives instantly over IMAP IDLE, with an optional macOS notification sound.

🧰

Self‑contained engine

EmailKit — a zero‑dependency Swift package doing IMAP, SMTP, MIME and OAuth2 (PKCE + XOAUTH2) directly on Network.framework.

💾

Download once, open instantly

Bodies are cached to disk and re‑opened with zero network — works offline, survives restarts. A background warmer fills the cache but always yields to you.

🎨

A theme you'll enjoy

A soft "aurora glass" look — frosted panels, gradient accents, glowing orbs — tuned for macOS 26 Liquid Glass, light and dark.

Private by default

Your mail talks directly to your providers. The AI is local. Credentials live in the macOS Keychain — this project ships with no secrets.

Install in a minute

Targets macOS 26 "Tahoe". Grab the signed, notarised .dmg from Releases, or build from source below.

# prerequisites: Xcode 26+, XcodeGen, (optional) Ollama for the AI
brew install xcodegen
brew install ollama && ollama pull llama3.1:8b   # optional, for the Copilot

git clone https://github.com/ic3y808/aether-courier.git
cd aether-courier
./build.sh                       # generate project + build → ~/Applications
open ~/Applications/Aether-Courier.app

Then Add Account (iCloud · Gmail · Outlook · Proton), pick your model in Settings → Model, and ask the Copilot to tidy your inbox.
